# Manual-Testing-Portfolio
Manual Software Testing Portfolio

This repository contains my manual software testing practice project for an e-commerce website.

## Project Contents

### Test Plan
Contains the testing objectives, scope, testing approach, environment, entry/exit criteria, risks, and responsibilities.

### Test Cases
Contains test cases covering:
- Login
- Signup
- Product Search

### Bug Reports
Contains sample bug reports documented during testing practice.

## Testing Approach

- Manual Testing
- Functional Testing
- Positive & Negative Testing
- Boundary/Validation Testing
- Regression Testing
